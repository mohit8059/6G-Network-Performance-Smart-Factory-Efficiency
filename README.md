# 🏭 6G Network Impact on Manufacturing Efficiency



## 📌 Project Overview
In the era of Industry 4.0 and 5.0, smart factories heavily rely on ultra-low latency communication for real-time AI-driven decisions and machine-to-machine (M2M) synchronization. However, network degradation (latency spikes and packet loss) can silently reduce production efficiency and increase defect rates without any mechanical failures. 

This project, developed in the context of advanced manufacturing environments like the **Thales Group**, reframes manufacturing analytics through a "connectivity-first" lens. It quantifies how 6G network performance directly impacts production speed, operational error rates, and overall manufacturing efficiency.

## ⚙️ Tech Stack
*   **Python:** Data Aggregation, Engineering & Logic
*   **Pandas:** Data Preprocessing & Custom KPI calculations
*   **Streamlit:** Frontend Web Application Deployment
*   **Plotly:** Interactive Data Visualization (Density Contours, Scatter, Box Plots)

## 📊 Key Features & Analytics Modules
*   **Network Stability Indexing:** Custom engineered metric combining latency and packet loss to classify network quality (High, Medium, Low).
*   **Network vs. Efficiency Dashboard:** Visualizes how network instability shifts machine efficiency profiles and throttles production speed.
*   **Quality & Error Impact Analysis:** Correlates packet drops with operational error rates and maps out defect concentration zones based on network latency.
*   **6G Optimization Insights:** Provides strategic diagnostics, including latency tolerance benchmarks and packet loss risk zones for specific machine operation modes.
